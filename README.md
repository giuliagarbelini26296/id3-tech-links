# ID3 TECH | Central de Links e Fast Assessment

Projeto de site estático, pronto para publicação no Render.

## Estrutura

- `public/index.html` — Central de Links
- `public/assessment.html` — Fast Assessment
- `public/assets/` — Estilos, JavaScript e logotipo

## Publicar no Render (Static Site)

1. Envie os arquivos desta pasta à **raiz** do repositório GitHub `giuliagarbelini26296/id3-tech-links`.
2. No Render: New > Static Site > Connect GitHub > selecione `id3-tech-links`.
3. Name: `id3-tech-links` (ou o nome livre sugerido pelo Render).
4. Branch: `main`.
5. Build command: `echo "Site estatico - sem build"`.
6. Publish directory: `public`.
7. Crie o serviço e espere o status de publicação. Teste a página principal e `/assessment.html` no endereço `.onrender.com` antes de adicionar domínio.
8. Depois, adicione `links.id3.com.br` em **Settings > Custom Domains** e só então substitua o CNAME `links` na Hostinger pelo **destino confirmado na tela do Render**.

## Dados e privacidade
